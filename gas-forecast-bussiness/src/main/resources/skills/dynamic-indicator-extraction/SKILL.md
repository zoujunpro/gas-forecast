# 动态指标定义抽取

## 目标

根据市场分析报告和训练上下文，提取可能影响预测目标的动态指标定义。

本 Skill 不调用钢联接口，不生成指标值，不创建永久特征定义，不修改模型固定特征关系。

## 输入

- 完整的 Markdown 市场分析报告；
- 预测目标；
- 地区、行业、客户和训练时间范围（存在时）；
- 训练时间粒度。

## 流程

1. 只分析输入报告中明确出现的信息。
2. 提取与预测目标存在清晰影响关系的指标定义。
3. 合并名称不同但定义、业务对象、粒度和计算依据相同的候选指标。
4. 删除缺少报告证据、无法定义或无法在后续取值的候选项。
5. 严格按照 [references/indicator-schema.md](references/indicator-schema.md) 输出 JSON，不附加 Markdown 或自然语言说明。

## 约束

- 每个指标必须保留报告原文证据。
- 不使用报告外知识补造指标。
- 不输出 `value`、历史序列、预测值或模拟值。
- 不生成 `feature_id`、`feature_code` 或 `feature_column`。
- 空结果返回 `{"indicator_definitions": []}`。
- 输出只属于当前训练批次，后续由独立的指标取值服务补充数据。
