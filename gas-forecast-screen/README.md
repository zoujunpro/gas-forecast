# 天然气智能预测大屏

独立纯前端项目：Vue 3 + Vite + ECharts + Canvas 2D。无需后端。

```sh
npm install
npm run dev
```

构建：`npm run build`。部署 `dist` 目录即可。

- `/public/dashboard.json`：指标、图表、洞察、任务和智能体模拟数据。
- `/public/maps/china.json`：本地省级 GeoJSON，来源为阿里云 DataV 地图边界服务。
- `src/TemperatureMap.vue`：固定视角地图，连续温度色带、省界、动态扩散波纹、暂停/播放。
- 温度值使用程序模拟，动画用于视觉展示，不代表实际气象数据；天气卡片同为模拟数据。
- 月度/旬度与天气/销量切换、全屏以及演示弹窗均可操作。平台业务入口仅展示说明弹窗。

截图中的工厂插画和品牌素材未提供，本版本通过 CSS 绘制科技背景，不能保证像素级一致。


## 知识资料与附件

知识库支持分类、正文检索、阅读和引用资料提问。可从知识库上传文件，单个文件限制 10MB；会话通过知识库的“基于此资料提问”关联资料。TXT、Markdown、CSV、JSON 可直接读取；PDF、Word、Excel、PPT 仅保留原文件并标记待解析。

上传文件保存在当前浏览器 IndexedDB，会话附件与公共知识库分开；会话记录保存在 localStorage。当前问答显示本地匹配的原文片段，尚未连接真实问答模型。清除浏览器数据会清除本地记录，其他设备不会自动同步。

### 查看完整节点图谱

在图谱探索顶部点击“全图总览”：画布包含原始 JSON 的全部 2,413 个节点和 9,218 条关系（含所有指标值），读取按原始关系预计算的布局；这是实例全图，与“查看本体结构”的类型统计不同。“全部对象”只清除目录筛选。总览收起大多数节点名称和连线文字以减少重叠，悬浮可看原始信息，选中可查看详情，点击节点查看原始属性；双击选中对象，全图已包含的节点不会重复添加。节点使用纯色二维圆形，名称在圆下方按缩放级别显示。


### 二维动态图谱与缩放文字

局部关系使用 G6 D3 力导向布局；全图总览直接读取 `public/customer-graph-layout.json` 的预计算坐标，保持全部原始节点和连线。节点按类型使用纯色，普通节点 44px，中心／选中节点 60px，名称置于圆形下方。总览按连接数调整节点大小，缩小时隐藏密集文字，放大或悬停查看信息。关系使用浅灰箭头，小型局部图显示关系名称，大图在悬停和选中时显示。

拖动空白区域平移画布，滚轮或放大镜按钮缩放；局部关系拖动节点使用 `drag-element-force`，拖动时固定当前位置、重新激活模拟，释放后解除固定，周围节点和连线实时响应；全图总览使用普通拖动，连线随动，避免对全部节点实时迭代。缩放和改色不重新布局。“复位”重新计算布局，“适应画布”调整视口显示所有当前节点。

局部图双击节点按每批 18 个追加邻居，重复双击继续增加该节点的邻居上限，不重复节点／关系；展开保留原有节点的位置作为布局起点和当前视口。单击高亮直接关联，点击空白取消选中。传导路径保持分层布局，支持单独拖动；当前原始附件未提供传导实例。

### 用户自定义配色

图谱只按实体类型配色，同类型节点保持同一种颜色。顶部“配色设置”显示每类实体的圆形铅笔按钮及节点数量；点击后可选预设色，或输入完整 HEX／使用自定义选色器后点击“应用颜色”。支持“恢复默认”，并说明节点数最多的类型及其占比。不再提供配色方式下拉或单节点颜色覆盖。

设置使用浏览器 localStorage 的 `wb-graph-colors-v1` 保存，作用于当前浏览器。旧版按类型设置的颜色会保留，旧版独立节点颜色不再生效。改色只刷新节点填充与图例，不重算布局，也不改变原始图谱或当前缩放／拖拽位置。

### 本体结构窗口

“查看本体结构”打开 `GraphSchema.vue`：顶部汇总实际实体类型、原始节点、关系组合（起点类型＋关系名称＋终点类型）和原始关系数量。结构图由 `repository.schema()` 的真实统计生成，使用 G6 渲染类型节点、方向箭头与同类型关系环线；配色沿用当前类型颜色。点击类型或关系可联动右侧明细，支持关系搜索、缩放、拖动和适应画布。

可切换到“关系明细”表格，数量列固定宽度并右对齐，窄屏表格在弹窗内部滚动。右侧“查看对象”关闭弹窗并切换对象目录类型。窗口支持 Escape 关闭、Tab 焦点循环与关闭后恢复触发按钮焦点。该图展示类型间的组合，不是实例全图，也不将原始关系视为已验证因果。


### 全图加载与交互性能

`npm run graph:layout` 通过 D3 在开发／构建阶段预计算全部原始节点的坐标，写入独立布局文件。`predev`／`prebuild` 会校验源 JSON 的 SHA256，数据不变则复用缓存；重新导入后需运行该命令或重启开发服务。浏览器校验缓存的来源、节点／关系数量及每个节点坐标，未匹配时使用确定性快速坐标，不减少或合并节点。

全图加载不在主线程运行持续力模拟；缩放／平移期间暂时隐藏关系线，停止后恢复。初始总览收起箭头和文字，选中或悬停显示对应关系的名称和方向。节点度数改为一次遍历统计；缩放不重复更新未变化的标签，改色只提交填充实际改变的节点，避免初始全量二次绘制。预计算位置文件不改变节点、关系或属性。


### 本体结构视觉规范

本体窗口采用紧凑标题栏，规模统计合并到标题右侧，主体保留类型筛选、视图切换、搜索、结构图与右侧关系列表。页面不展示演示性、来源校验或操作教学文案。右侧每条关系保持单行，数量固定右对齐；选中关系后显示名称与数量详情。窗口按可用视口高度分配画布空间，窄屏改为上下排列。统计和关系仍来自现有数据，未更改计算口径。

## 天然气传导情景数据

当前图谱由两个独立数据文件组成：`public/customer-graph.json` 保留原始 2,413 个节点、9,218 条关系及实绩；`public/transmission-scenarios.json` 新增 97 条规则、873 组情景（每条规则 3 个适用地区 × 温和／典型／强化），共 6,820 个节点、14,970 条关系。页面合计 9,233 个节点、24,188 条关系。

- 规则来自《天然气事件终端传导情景.xlsx》明细，保留文件 SHA256、工作表及原始行号。实际明细 97 条，分类汇总页声明 102 条，生成以明细为准。《项目里程碑计划》仅作为范围参考，不生成已发生事件。
- 标准化适用条件、时滞假设和终端行业；对碳价、期货、电价改革、利用率等 12 条存在必然性或口径问题的链路保留原文并记录校正。一般机制参考 EIA [供需与价格因素](https://www.eia.gov/energyexplained/natural-gas/factors-affecting-natural-gas-prices.php)、[燃烧排放系数](https://www.eia.gov/environment/emissions/co2_vol_mass.php)。这些材料不证明某一企业或事件真实发生。
- 32 类情景包含明示的定量扰动输入（如降温、费率调整、停输天数），其余使用定性强度；所有扰动、地区和强度都是设定条件，不是观测数据，不输出未经标定的销量增减或置信概率。
- 新增节点与关系均标记 `simulated:true`，属性保留“情景推演／待业务验证”。客户匹配同时满足行业与所在地；LNG重卡／船用需求不映射到 CNG 加气站，不修改企业月销量。
- 搜索“极端冷冬”“管输费率下调”可进入传导路径，或从 CNG 加气站／企业查看适用情景。下拉框切换区域和强度；每次路径严格限定一个情景。查询现有行业、工厂或客户时，仅展示对应行业分支。无对应情景的对象隐藏路径入口。
- `npm run graph:scenarios` 使用 `data/transmission-workbook-sources.json` 与 `data/transmission-profiles.txt` 确定性重建数据。开发／构建前自动生成，随后生成独立的全图位置缓存 `public/exploration-graph-layout.json`。原始静态图缓存仍保留，新增数据不触发浏览器全量力导计算。
- `src/graphDatasets.js` 负责合并并拒绝 ID 覆盖或无效端点，`graphRepository.js` 负责按情景隔离路径。未来 Java／Neo4j 可沿用节点、关系、`scenarioId` 与规则来源字段。

预测详情视觉参考 WorkBuddy 官网的深灰文字、黑色主按钮、青绿色强调和浅灰中性控件，使用系统字体。四个模块持续在同一页面展示，数据、候选模型及导出字段保持不变。

## 知识库列表

知识库采用紧凑列表，资料名称和单行摘要、分类、状态、更新时间及查看／提问操作同排展示。默认每页 20 条，可切换 50／100 条，支持首尾页、页码跳转、分类与可阅读状态筛选和更新时间／名称排序。小屏将分类、日期与状态合并到名称下方。

工作台采用完整视口布局，欢迎区、业务快捷入口和输入框组成同一内容区域；侧栏提供最近预测、会话检索及管理。手机使用横向导航，最近预测可打开独立列表；长消息输入自动增高，焦点只呈现在输入容器边框。参考腾讯 WorkBuddy 官方[新建任务栏](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)的入口组织与提示词预览方式，悬停快捷入口不覆盖已输入内容。

主界面不再展示研发与演示标签，展示文案由 `workspacePresentation.js` 转换，原始 JSON、来源说明和 `simulated` 标志保留。用户输入与上传文件正文不改写。预测记录的计算方式、资料来源、训练和调用状态仍可在对应信息栏查看，未将规则计算或原文匹配冒充外部模型运行。

会话结果继续使用相同业务系数，生成记录附带 `calculationMethod:rules`、`modelExecuted:false`。天气／销量／事理／知识快捷入口现在进入各自场景，不再误触发当前预测场景。此调整不接入模型、调度、上传服务器或跨设备同步服务。
