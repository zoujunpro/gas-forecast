# 结果解释与异常

## 列表

- 展示实际 records 中的名称和必要标识。
- 说明 total、当前返回数量以及是否已覆盖全部。
- 空列表明确说明没有符合当前条件的数据，并复述主要筛选条件。
- 多个同名客户同时展示地区、行业和编码，禁止模型自行选一个。

## 状态

- 任务状态只采用状态工具的实时结果。
- `PENDING`、`EXECUTING`、`WAITING_TRAINING` 均表示尚未完成。
- `FAILED`、`CANCELLED` 必须结束前端进行中状态并展示原因。
- 用户只查询状态时不得顺便恢复、重试、训练或预测。

## 失败

- `NOT_FOUND`：建议补充名称、地区、行业或检查编号。
- `NEED_INFORMATION`：只追问缺失字段。
- `MULTIPLE`：展示完整候选并等待选择。
- 权限错误：说明无权访问，不暗示数据不存在。
- 临时技术错误：说明暂时不可查询，不编造旧数据作为当前结果。

只读查询不需要用户确认，也不得调用任何创建或修改任务的工具。
