# 查询选择与参数

| 用户请求 | 工具 |
| --- | --- |
| 查询地区列表 | `region_list` |
| 查询行业列表 | `industry_list` |
| 按地区、行业或名称筛选客户 | 先用搜索工具取得标准编码，再调用 `customer_list` |
| 查询单个客户详情或解析名称 | `customer_search` |
| 查询任务实时状态 | `task_status_get` |
| 查询任务执行步骤 | `task_steps_get` |
| 判断未知业务编号类型 | `business_reference_resolve` |

## 范围规则

- 地区、行业、客户名称必须优先取自本轮输入或页面绑定范围。
- 用户本轮只问“浙江城燃有哪些客户”时，不得继承上轮客户名称或客户编码。
- “城市燃气”“城镇燃气”“城燃”表达统一理解为城燃，标准编码通过工具解析。
- 地区名称先用 `region_search` 解析，行业名称先用 `industry_search` 解析；只有唯一结果才把编码传给 `customer_list`。
- 任一解析结果为多个候选时立即展示候选并等待选择，不继续查询客户列表。
- 用户说“这个客户”时，只有会话中存在唯一已确认客户才能继承；否则追问。
- 用户要求“全部”“所有”“完整列表”时启用工具支持的全量参数或安全翻页，不把默认第一页当成全部。
- 任务号、客户编码等标识不得根据名称或格式猜测。

工具 Schema 未要求的过滤参数不得传递。条件互相冲突时先请用户确认，不擅自放宽范围。
