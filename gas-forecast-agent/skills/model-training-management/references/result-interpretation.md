# 训练结果解释

只有训练真实成功后才能调用 `training_result_get` 并解释指标。

- 展示模型名称、版本、训练范围、样本量、训练耗时和服务端实际返回的指标。
- 实际值含零值时，不把普通 MAPE 作为可靠的唯一指标；优先结合 WMAPE、SMAPE、MAE 或 RMSE。
- 指标为 null、非有限值或缺失时明确说明不可用，不补零，不猜测。
- 回测表现不代表未来一定准确，禁止承诺预测效果。
- 不比较工具没有返回的模型或指标。
- 训练成功只说明模型产出成功，不代表后续预测任务已经完成。

失败时说明：

1. 失败发生在哪个阶段。
2. 稳定错误码和业务原因。
3. 是否允许等待、恢复或重试。
4. 用户需要补充或修正的内容。

前端状态必须以真实任务状态结束；失败或取消后不得继续显示执行中。
