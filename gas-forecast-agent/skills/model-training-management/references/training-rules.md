# 训练参数与校验

实时 MCP Schema 是格式和必填项的最终依据。模型负责收集信息，Java 负责最终数据质量、权限和状态校验。

## 客户与范围

- 单客户训练必须获得唯一 `customerCode`。
- 批量训练必须有明确地区、行业或客户集合，并在调用前复述影响范围。
- 本轮新客户或新行业出现时，丢弃记忆中的旧客户编码和旧行业编码并重新解析。
- 客户、地区、行业存在冲突时停止，不得自行选择一个看似合理的组合。

## 训练区间

- `ALL`：使用全部符合条件的历史数据。
- `RECENT`：必须提供 `trainingPeriods`，表示最近 N 个模型训练周期；周期单位由模型粒度决定，可能是日、旬或月。
- `RANGE`：必须同时提供 `trainingStartDate` 和 `trainingEndDate`，结束日期不得早于开始日期。
- 用户明确给出日期范围时优先采用 `RANGE`。
- `forceRetrain=true` 会创建新的训练，必须获得用户确认。

## 数据质量

数据质量由 Java 最终裁决。若返回阻断：

- 停止训练，不自动缩短时间范围或删除异常数据。
- 说明缺失、重复、非数值、样本不足或时间不连续等具体问题。
- 若返回可调整范围，只把建议告诉用户，等待用户决定。
- 警告不等于允许模型自行忽略；是否继续必须遵循工具返回的确认要求。

参数完整后只调用一次 `training_start`。返回批次号后结束本轮。
