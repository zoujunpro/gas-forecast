# 预测结果分析

## 适用场景
用户希望理解预测结果、训练指标、变化趋势、
误差原因，或者比较不同客户、不同模型的表现。

## 执行规则
1. 必须先通过 MCP 获取真实业务数据。
2. 用户未指定批次时，优先查询符合条件的最新结果。
3. 分析预测误差时，必须区分预测值与实际值。
4. 比较模型时，尽量使用相同时间范围和评价口径。
5. 数据不足时，说明缺失信息，不得编造结论。
6. 不允许触发训练、预测或修改业务数据。

## 输出要求
- 先给出关键结论。
- 展示支撑结论的实际数据或指标。
- 区分已验证的事实和可能原因。
- 必要时给出进一步分析建议。
